# Catholic Context Governance

This directory contains the detailed governance standards that protect theological integrity independently from product and commercial decisions.

The root [GOVERNANCE.md](../GOVERNANCE.md) contains the founding governance principles.

## Governance workstreams

Planned standards include:

- theological reviewer qualifications
- review evidence and auditability
- source and authority classification
- conflicts of interest
- disputed-content escalation
- material-change and re-review rules
- correction and appeals process
- relationship between community voting and formal review
- financial independence of theological governance

Founding panel appointments:

- [`founding-reviewer-panel.md`](founding-reviewer-panel.md) — **Channing Decker** first theological reviewer (platform auth; no GitHub required)

Reviewer platform implementation notes: [`website/README.md`](../website/README.md)

Until these standards are established, theological material should be treated conservatively and labeled according to its actual review status.
