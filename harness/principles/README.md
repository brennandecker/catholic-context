# Catholic Harness Principles

Harness principles translate Catholic sources into explicit, inspectable, model-agnostic requirements for AI systems.

The governing provenance chain is:

```text
Catholic source
      ↓
Catholic Context interpretation
      ↓
Harness normative requirement
      ↓
Implementation
      ↓
Eval
```

A Harness principle is **not itself an act of the Magisterium**. Catholic Context must distinguish the authoritative source from the project's engineering interpretation of that source.

## Normative vocabulary

Harness specifications use standards-style language:

- **MUST** — required for conformance
- **MUST NOT** — prohibited for conformance
- **SHOULD** — strongly recommended; exceptions require justification
- **MAY** — optional

## Required principle metadata

Each mature principle should identify:

- stable principle ID
- title
- status and review state
- Catholic sources and exact references
- source authority/classification where available
- Catholic Context interpretation
- normative requirements
- prohibited behaviors
- implementation notes
- linked Evals
- version/revision history

## Magnifica Humanitas

Pope Leo XIV's 2026 encyclical *Magnifica Humanitas*, on safeguarding the human person in the time of artificial intelligence, is a foundational source for the Harness's technological anthropology and AI-design principles.

It does not replace the broader Catholic tradition. Harness principles should also draw on Scripture, the Catechism, conciliar teaching, Catholic social doctrine, moral theology, and other appropriate authoritative sources.

The first draft principles derived from *Magnifica Humanitas* are intentionally marked for theological review before becoming normative Catholic Context Harness requirements.
