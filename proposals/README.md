# Correction proposals

Structured correction proposals opened from Catholic Context reviewer tools land here as Markdown files on pull-request branches (`proposals/open/<id>.md`).

- Attribution uses the proposer’s **platform public username**, not a GitHub login.
- Reviewers act in the site UI (`/review`); maintainers merge on GitHub.
- Do not treat files in this directory as canonical doctrine — apply accepted changes into `context/**/*.yaml`.
